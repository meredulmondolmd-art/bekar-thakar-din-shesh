# বেকার থাকার দিন শেষ

নতুন Node.js + Express + PostgreSQL starter project.

## চালানো
1. Node.js 20+
2. `npm install`
3. `DATABASE_URL`, `SESSION_SECRET`, `ADMIN_PASSWORD` সেট কর
4. `npm start`

নতুন account-এ ৳70 balance থাকে। Referral link/code দিয়ে signup হলে referrer ৳20 পায়।
Withdrawal manual admin approval-এর মাধ্যমে হবে; automatic bKash/Nagad/Rocket API নেই।
Admin password frontend code-এ রাখা হয়নি। বাস্তবে চালুর আগে production security, business/legal compliance এবং payment-provider requirements যাচাই কর।
